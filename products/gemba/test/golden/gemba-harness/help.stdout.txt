gemba-harness 0.1.0 — Run agents and capture NDJSON traces for agent evaluations or multi-agent collaboration

Usage: gemba-harness <command> [options]

Commands:
  run                  Run a single agent autonomously on a defined task
  supervise            Run a supervisor–agent relay, the typical shape for agent-as-judge evaluations
  facilitate           Run a facilitator with N participants, the typical shape for multi-agent collaboration
  discuss              Run an async, suspendable discussion: Chair + N participants + bridge callback
  output               Read NDJSON from stdin and emit a structured or readable form
  tee [output.ndjson]  Stream readable text to stdout while it saves raw NDJSON to a file
  callback             Extract the terminal summary from an NDJSON trace and POST it to a callback URL
  scan-logs            Scan a run's log archive for secret literals. Exit non-zero on any hit. Fail closed on an unreadable archive

Options:
  --format=<string>  Output format (json|text)
  --help, -h         Show this help
  --version          Show version
  --json             Output help as JSON

Examples:
  gemba-harness run --task-file=task.md --output=trace.ndjson
  gemba-harness run --task-file=task.md --work-tracker=filesystem --output=trace.ndjson
  gemba-harness supervise --task-file=task.md --lead-profile=judge --agent-profile=coder --output=trace.ndjson
  gemba-harness facilitate --task-file=task.md --lead-profile=lead --agent-profiles="security-engineer,technical-writer" --output=trace.ndjson
  gemba-harness discuss --task-file=task.md --lead-profile=release-engineer --agent-profiles="staff-engineer,security-engineer" --discussion-id=GD_kw...
  gemba-harness output --format=text < trace.ndjson
