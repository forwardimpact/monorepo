## Empowered Engineers: Prepare for the Day Ahead

**Trigger:** The todo list grows long. Each morning the engineer scans it to
find the few items that matter. That scan wastes the first minutes of the day.

**Big Hire:** Help me see only the todos relevant to my current work. Do not
delete or reorganize the rest. → **todo**

**Little Hire:** Help me narrow a long list to the items that mention a project
or keyword. → **todo**

**Competes With:** a scroll through the whole list; a pipe from `todo list` into
`grep`; separate lists per project.

**Forces:**

- **Push:** A flat list grows without bound. Every item costs attention.
- **Pull:** A single command that shows just the items that match.
- **Habit:** A re-read of the entire list each morning.
- **Anxiety:** A filter might hide an item that actually mattered.

**Fired When:** the list is short enough that a filter adds friction, or the
engineer moves to a richer task manager.
