# unitconv

A tiny command-line tool that converts between metric and imperial units.

```sh
unitconv 10 km mi     # -> 6.2137
unitconv 200 g oz     # -> 7.0548
```

It serves engineers who want a quick unit conversion at the terminal. They do
not want to open a browser. They do not want to trust a random web result. It
ships as one binary. It uses no network. It has no dependencies beyond the
Node.js standard library.
